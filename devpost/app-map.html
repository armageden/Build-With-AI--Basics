Architecture & App Map

DiffStory — The Post-Prompt Receipt

A post-prompt audit tool for AI coding agents that compares the prompt you typed against the git diff returned, deterministically flagging unrequested code mutations and generating a 1-click restore prompt.

🎯 Core Architectural Takeaway

Modern AI applications often fail by delegating everything—including verifiable ground truth—to non-deterministic LLM calls. DiffStory proves a powerful hybrid pattern:

Responsibility Component Guarantees
Truth & Classification (Did the prompt ask for this?) src/lib/receiptEngine.js 100% Deterministic: Zero hallucinations, instant audit, verifiable word-for-word proof.
Impact & Reversion (What did it break & how to restore?) src/lib/liveModel.js (Gemini) Strictly Bounded: Only called for unmentioned hunks; output formatted as concise impact + copyable prompt.

🗺️ The 3-Location Code Tour (Single Click Trace)

When a user clicks "Generate Post-Prompt Receipt", execution flows sequentially through exactly three distinct code locations:

Location 1 · Orchestration
Workbench UI & State
src/App.jsx

Captures the user prompt & diff, dispatches the deterministic engine, immediately renders the sorted cards, and fires bounded async LLM requests for unmentioned hunks.

Location 2 · Deterministic Engine
Pure Token Intersection
src/lib/receiptEngine.js

Splits unified diff on @@, extracts tokens from mutated lines (skipping syntax boilerplate), computes intersection with prompt tokens, and sorts amber warning hunks to top.

Location 3 · Bounded Model
Impact & Restore Generation
src/lib/liveModel.js

Sends structured contract to Gemini exclusively for NOT MENTIONED hunks to produce the 1-sentence impact statement and 1-click restore prompt.

🛡️ Graceful Degradation & Zero-Hallucination Fallback

Per PRD Rule 3, DiffStory will never fake or silently mock AI output:

  • If offline, rate-limited (503/429), or no API key is supplied, the amber and green hunk cards still render with 100% deterministic accuracy.
  • The AI receipt box transparently indicates: "Live model unavailable — deterministic token receipt above is complete."
  • Users can configure or test their custom Gemini API key anytime via the top-bar key dialog.
